# codertrovecyber

Internal cyber security platform for Coder Trove.

- admin/ : admin portal (Next.js)
- app/ : user portal (Next.js)
- api/ : backend API (Strapi, Postgres)

## Run locally

You need Docker Desktop running.

```
docker compose up
```

- User portal: http://localhost:3000
- Admin portal: http://localhost:3001
- API admin: http://localhost:1337/admin

Stop with Ctrl+C. The first start takes several minutes.
